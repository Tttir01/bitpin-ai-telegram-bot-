# Arbitrage AI MVP 0.1

پنل فارسی رصد اختلاف قیمت بیت‌پین و Binance؛ این نسخه فقط داده عمومی را می‌خواند و سفارش واقعی ثبت نمی‌کند.

## اجرا
1. Python 3.11+ نصب کنید.
2. در این پوشه اجرا کنید:
   `pip install -r requirements.txt`
3. سپس:
   `streamlit run app.py`

## استقرار
در Render یک Web Service بسازید و Root Directory را `arbitrage-ai-mvp` قرار دهید.
Build Command: `pip install -r requirements.txt`
Start Command: `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`

## محدودیت‌ها و ریسک
- هیچ سفارش، برداشت یا دسترسی به موجودی حساب وجود ندارد.
- کارمزدهای پنل نمونه‌اند و باید با کارمزد واقعی جایگزین شوند.
- فقط جفت‌ارزهای دارای quote یکسان مقایسه می‌شوند؛ IRT و USDT خودکار تبدیل نمی‌شوند.
- هزینه انتقال، نرخ تبدیل ارز، لغزش قیمت، عمق دفتر سفارش، محدودیت‌های برداشت/واریز و ریسک طرف مقابل لحاظ نشده‌اند.
- اختلاف نمایش‌داده‌شده سیگنال قطعی یا تضمین سود نیست.
- کلید API خصوصی را در GitHub یا چت قرار ندهید.
