# 🤖 Bitpin AI Telegram Bot

یک ربات معامله‌گر و دستیار هوشمند تلگرامی نوشته شده با **Python** که قیمت‌های لحظه‌ای ارزهای دیجیتال را از صرافی **بیت‌پین (Bitpin)** دریافت کرده و با استفاده از هوش مصنوعی **DeepSeek** تحلیل بازار ارائه می‌دهد.

## ✨ ویژگی‌ها
- دریافت قیمت لحظه‌ای بیت‌کوین، تتر و اتریوم به تومان از صرافی بیت‌پین (`/prices`)
- تحلیل هوشمند بازار و دریافت پیشنهاد معاملاتی از هوش مصنوعی DeepSeek (`/analyze`)
- امنیت بالا با استفاده از متغیرهای محیطی (`.env`)
